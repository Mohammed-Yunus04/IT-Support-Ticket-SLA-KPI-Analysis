# IT-Support-Ticket-SLA-KPI-Analysis

📊 IT Support Ticket SLA & KPI Analysis | Excel


📌 Project Overview

This project focuses on analyzing IT support ticket data using Microsoft Excel to evaluate service performance, monitor SLA compliance, and identify areas for improvement.

The analysis explores ticket resolution time, priority levels, support teams, and ticket categories through formulas, KPI metrics, and charts.

🎯 Objectives

- Evaluate overall IT support performance.
- Measure SLA compliance and identify SLA breaches.
- Analyze ticket resolution times.
- Compare performance across support teams.
- Understand ticket distribution by priority and category.
- Monitor monthly ticket and SLA trends.

🛠️ Tools & Skills

- Microsoft Excel
- Data cleaning and organization
- IF function
- INDEX & MATCH functions
- KPI calculations
- Charts & data visualization
- Dashboard creation

📈 Key Performance Indicators

KPI| Result
Total Tickets| 2,500
Resolved / Closed| 2,130
Pending Tickets| 370
SLA Compliance| 70.56%

🔍 Analysis Performed

- SLA Analysis: Evaluated tickets that met or breached their SLA targets.
- Team Performance: Compared SLA compliance across assigned teams.
- Priority Analysis: Examined ticket volume by priority level.
- Category Analysis: Identified ticket distribution across categories.
- Resolution Analysis: Reviewed ticket resolution time.
- Monthly Trend: Examined SLA performance over time.

📊 Dashboard

The Excel dashboard summarizes ticket performance using KPI cards and charts to make key metrics easier to understand.

📁 Project Files

- "SLA_KPI_Tickets_Dashboard.xlsx" — Contains the dataset, SLA rules, calculations, analysis, and dashboard.

💡 Key Takeaways

- Overall SLA compliance was approximately 70.56%.
- SLA performance varied across assigned teams.
- Pending tickets need to be monitored separately from resolved tickets.
- KPI reporting helps identify service performance improvement opportunities.

This is a beginner-level data analysis project created to practice Microsoft Excel skills and understand how data can be used to monitor IT service performance and support decision-making.
